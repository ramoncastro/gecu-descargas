
# GECU – Gestión Curricular y Evaluación

**Herramienta gratuita para el profesorado.**

GECU es una aplicación de escritorio para Windows diseñada para facilitar la gestión curricular y la evaluación educativa.

## Versión actual: 1.0.1

### Descarga
Consulta la sección [Releases](../../releases) para descargar la última versión.

### Características
- Gestión de programaciones didácticas.
- Importación de elementos curriculares.
- Gestión de unidades y criterios de evaluación.
- Creación y gestión de aulas.
- Registro y tratamiento de calificaciones.
- Generación de informes de evaluación.

### Requisitos
- Windows 10 o Windows 11.
- Instalación mediante el instalador proporcionado.

### Licencia de uso
GECU es gratuito para uso personal y educativo, conforme a las condiciones de su licencia.
